# UniDate

A Flutter-based dating application specifically designed for university students.

## Features (Planned)

- **Student Verification:** Ensure users are actual students using university email domains.
- **Campus-based Matching:** Find matches within your own university or nearby campuses.
- **Interest-based Profiles:** Highlight academic interests, clubs, and hobbies.
- **Safe Dating:** Integrated safety features and reporting.

## Getting Started

This project is built with Flutter.

### Prerequisites

- Flutter SDK
- Android Studio / VS Code
- Dart SDK

### Installation

1. Clone the repository.
2. Run `flutter pub get` to install dependencies.
3. Run the app using `flutter run`.
